# Prácticas de SQL — Tema 4

Este repositorio reúne tres prácticas realizadas con SQL y SQLite. Incluye los scripts de consulta y las bases de datos utilizadas.

## Práctica 1: registro de animales de ParaiZoo

Se crea y completa una base de datos para registrar los animales de un zoológico.

- **Base de datos:** `PRACTICA1/data/parazoo.db`
- **Scripts:** `PRACTICA1/src/`
- **Contenidos:** creación de la tabla `ParaiZooHuesped` e inserción de los datos de Parches, Spirit, Perla, Fresa y Nilo.
- **Conceptos:** creación de tablas e inserción de registros.

## Práctica 2: consultas sobre películas

Se realizan consultas sobre una base de datos de películas para filtrar y mostrar información según distintos criterios.

- **Base de datos:** `PRACTICA2/data/moviebig.db`
- **Scripts:** `PRACTICA2/src/`
- **Contenidos:** diez ejercicios sobre presupuestos, ingresos, valoraciones, popularidad, fechas, duración y texto.
- **Conceptos:** `SELECT`, filtros con `WHERE`, funciones de fecha, texto y operaciones numéricas.

## Práctica 3: ordenación y filtros avanzados

Se amplían las consultas sobre películas usando condiciones y criterios de ordenación más variados.

- **Base de datos:** `PRACTICA3/data/moviebig.db`
- **Scripts:** `PRACTICA3/src/`
- **Contenidos:** seis ejercicios sobre país de producción, valoraciones, votos, fechas y títulos.
- **Conceptos:** `ORDER BY`, `DISTINCT`, `BETWEEN`, `IN`, `IS NULL`, `COALESCE` y operadores `AND` y `OR`.

## Organización del repositorio

- `src/`: scripts SQL de cada práctica.
- `data/`: bases de datos SQLite utilizadas.
- `docs/`: presentaciones, instrucciones u otros materiales de referencia.
